# 💙 Power BI Health Analytics Dashboard

An interactive Power BI dashboard providing a clear, business-ready view of key health and fitness metrics, with dynamic user-level and time-based analysis.

## 🎯 Objective
To design a dashboard that goes beyond visuals — one that makes health data genuinely easier to understand and supports better, faster decision-making.

## 🔍 Key Insights
- Average Daily Steps
- Average Health Score
- Average Calories Burned
- Average Heart Rate
- Total Exercise Sessions
- Health Score Trend Analysis
- Year / Quarter / Month analysis
- Dynamic User Selection

## 🛠️ Tools & Technologies
- Microsoft Excel (data exported as CSV)
- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization

## 🧠 Approach
1. **Data Modeling** — Exported health/fitness data from Excel as CSV, imported it into Power BI, and structured it for efficient querying and time-based analysis.
2. **DAX Measures** — Built measures for daily/period averages, trend scoring, and session counts.
3. **Interactivity** — Added dynamic user selection and Year/Quarter/Month slicers so the dashboard adapts to any individual or time period.

## 💡 Key Learning
A good dashboard isn't just about beautiful visuals — it should make data easier to understand and support better decision-making.
